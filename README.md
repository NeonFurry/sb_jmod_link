# SB <-> JMod Link

**Версия: 7.3**

Аддон для Garry's Mod, который связывает энергосистемы **Spacebuild (SB)**, **JMod** и **CAF (Resource Distribution / Life Support)** в единую сеть. Позволяет перекачивать энергию между банками JMod, генераторами SB и хранилищами CAF (`storage_energy` и любыми другими устройствами, зарегистрированными в RD-сети).

> ⚡ Простой пример: банк JMod питает лимональный генератор, а хранилище CAF заряжается от SB-реактора — всё через один тул.

---

## Возможности

- **Двусторонняя перекачка энергии** — Spacebuild (`energy`) ↔ JMod (`Electricity`) ↔ CAF/RD.
- **Умное распознавание устройств** — через `RD.GetEntityTable`: любые девайсы Life Support цепляются без списка исключений.
- **Тул «SB <-> JMod Link»** — соединение устройств в пару кликов.
- **Физический трос или визуальный луч** между связанными устройствами (настраивается).
- **Удаление связей по клавише R** — наведи на устройство с связями и нажми R.
- **Гибкая скорость перекачки** — от 1 до 100 000 ед/сек, задается в меню тула.
- **Горячая перезагрузка** — обновление аддона без перезапуска игры.

## Установка

1. Скопируйте папку `sb_jmod_link` в `garrysmod/addons/`.
2. Убедитесь, что установлены и включены аддоны-поставщики ресурсов:
   - **Spacebuild / CAF** (Resource Distribution, Life Support);
   - **JMod**.
3. Перезапустите GMod **или** загрузите карту заново.
4. Включите RD **до** спавна накопителей — иначе устройства не попадут в реестр и не распознаются.

Структура аддона:

```
sb_jmod_link/
    README.txt
    lua/autorun/sb_jmod_link.lua              — ядро: классификация, связи, перекачка, команды
    lua/autorun/server/...                    — серверная часть
    lua/weapons/gmod_tool/stools/...          — тул «SB <-> JMod Link»
    sb_jmod/transfer.lua                      — насос (перекачка ресурсов)
    sb_jmod/rope.lua                          — физический трос
    sb_jmod/caf.lua                           — мост RD/CAF
    sb_jmod/autolink.lua                      — патч Auto Link Tool (rd3_dev_link)
```

## Использование

### Тул «SB <-> JMod Link»

Находится в категории **Construction** (или *JMod Bridge* — зависит от сборки).

| Действие | Результат |
|---|---|
| **ЛКМ** по устройству | Выбрать первое устройство; второй ЛКМ — создать связь |
| **ПКМ** по первому устройству | Задать цель 1; следующая ПКМ — цель 2; ещё одна ПКМ — создать связь |
| **R** по устройству с связями | Убрать **все** связи этого устройства (вместе с тросом) |
| **R** по устройству без связей / в пустоту | Сбросить выбор |

В меню тула настраиваются:
- **Скорость перекачки** (ед/сек);
- **Физический трос** (вкл/выкл — иначе между устройствами рисуется лазерный луч);
- **Провис троса**.

### Консольные команды

| Команда | Описание |
|---|---|
| `sb_jmod_dump` | Список всех связей: классы устройств, типы, скорость, ресурс (для админов) |
| `sbjmod_select` | Выбрать устройство под прицелом |
| `sbjmod_link` | Связать выбранное устройство с устройством под прицелом |
| `sbjmod_reset` | Сбросить выбор |
| `sbjmod_reload` | Перезагрузить серверные модули аддона (для админов) |
| `sbjmod_reload_cl` | Перезагрузить клиентскую часть (в консоль игрока) |

## Как это работает

Ядро аддона — функция `SB_JMOD.Identify`, которая определяет тип устройства:

1. **JMod** — энтити имеет методы `GetElectricity` / `SetElectricity`;
2. **SB** — энтити имеет методы `GetResourceAmount` / `SetResourceAmount`;
3. **CAF (RD)** — устройство зарегистрировано в RD-сети через `RD.GetEntityTable` (покрывает `storage_energy`, генераторы и любые другие девайсы Life Support);
4. Запасной вариант по префиксам классов (`storage_`, `generator_`, `other_`, `residue_`), если RD ещё не успел зарегистрировать свежезаспавненный девайс.

Связи синхронизируются с клиентом по сети (`SBJMOD_Links`, каждые 5 секунд) — для отрисовки лучей. Перекачка выполняется на сервере таймером раз в секунду.

## Совместимость

- ✅ Spacebuild (энергосистема `energy`)
- ✅ JMod (ресурс `Electricity`)
- ✅ CAF / Resource Distribution — через реестр RD
- ✅ Auto Link Tool (`rd3_dev_link`) — умеет подключать банки JMod к нодам RD-сети после патча из модуля `autolink`

## Устранение неполадок

| Проблема | Решение |
|---|---|
| Тул пишет «Это не устройство SB/JMod/CAF» | Убедитесь, что RD включён **до** спавна устройства; пересоздайте устройство |
| В `sb_jmod_dump` у банка стоит `?` | Адаптер не подошёл под класс банка — сообщите класс (из спавн-меню) |
| Связь создана, но энергия не идёт | Проверьте, что в `transfer.lua` есть ветка для типа `caf` через `RD.GetResourceAmount` / `RD.SetResourceAmount` |
| Тул не появился в меню | Полный перезапуск игры — тул регистрируется загрузчиком |
| Трос не исчезает | Нажмите R по устройству ещё раз или проверьте вывод `sb_jmod_dump` |
