# SB <-> JMod Link

Соединяет энергосистемы JMod, Spacebuild (SB) и CAF в единую сеть. Связывайте генераторы, банки энергии и потребители одним тулом — энергия будет перетекать между системами автоматически.

**Текущая версия: 7.3**

---

## ⚠️ Важно знать перед установкой

Этот аддон **не добавляет в игру новые сущности, генераторы или батареи**. Он предоставляет только:
*   **Тул связи** (в категории Construction) для создания энергосетей.
*   **Ядро логики** для автоматического перераспределения энергии между устройствами других модов.

Без установленных зависимостей аддон будет работать «вхолостую» — тул появится, но связывать будет нечего.

---

## Обязательные зависимости

Для работы аддона необходимы:

*   **JMod** — даёт устройства с системой `Electricity` (банки, генераторы, потребители).
*   **Spacebuild (SB)** или **CAF** — даёт устройства на ресурсе `energy` (реакторы, аккумуляторы, сети).

> Если не установить JMod или Spacebuild, в меню спавна не появится ни одного устройства, которое можно связать этим тулом.

---

## Возможности

*   Единый тул связи для устройств JMod (Electricity), Spacebuild и CAF (ресурс `energy`).
*   **Равный делёж энергии** между связанными устройствами: суммарный запас делится на равные доли с учётом ёмкостей — энергия идёт туда, где её меньше.
*   **Правила безопасности сети**, чтобы энергия не текла против логики:
    *   генератор → банк / потребитель — разрешено;
    *   банк ↔ банк — равный делёж;
    *   потребитель → кто угодно — **запрещено**;
    *   банк → генератор и генератор ↔ генератор — **запрещено**.
*   Автоматическое определение ролей устройств по имени класса:
    *   **генератор** — `generator`, `gen_`, `_gen`, `powersource`, `reactor`;
    *   **потребитель** — `turret`, `sentry`;
    *   **накопитель** — всё остальное (банки, батареи).

## Команды консоли

| Команда | Назначение |
| --- | --- |
| `sbjmod_transferlog 1` | Показывать перекачку энергии в консоли (0/1, сохраняется) |
| `sbjmod_test_energy` | Диагностика устройства под прицелом: роль, тип, каналы заряда |

Пример вывода диагностики:

```
[SBJMOD] === Диагностика: ent_jack_gmod_ezpowerbank ===
Роль: bank | Тип: jmod
GetElectricity -> ok=true val=420
MaxElectricity = 1000
[SBJMOD] === Конец диагностики ===
```

## Установка

1. Скачайте аддон (подписка в Мастерской или распакованная папка в `garrysmod/addons/`).
2. Обязательно установите зависимости (JMod и/или аддоны на базе Spacebuild/CAF) — модуль автоматически определит, что из этого присутствует.

---

## Быстрый старт

1. Заспавньте банк энергии (например, `ent_jack_gmod_ezpowerbank` из JMod) и генератор.
2. Возьмите тул **SB <-> JMod Link** (категория Construction) и кликните по первому устройству, затем по второму — связь создана.
3. Энергия начнёт перетекать: включите `sbjmod_transferlog 1`, чтобы видеть поток в консоли.
