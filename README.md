# SB <-> JMod Link

Соединяет энергосистемы JMod, Spacebuild (SB) и CAF в единую сеть. Связывайте
генераторы, банки энергии и потребители одним тулом — энергия будет перетекать
между устройствами автоматически.

**Текущая версия: 7.3**

## ⚠️ Важно знать

Этот аддон **не добавляет в игру новых сущностей, генераторов или батарей**.
Внутри только:

* **Тул связи** (категория Construction) для создания энергосетей между
  устройствами других аддонов.
* **Серверная логика**, которая автоматически перераспределяет энергию
  между связанными устройствами.

Без установленных зависимостей аддон работает «вхолостую»: тул появится,
но связывать будет нечего.

---

## Зависимости

Аддон — прослойка, и для работы ему нужны устройства других модов:

| Аддон | Что даёт |
|---|---|
| **JMod** | Устройства с системой `Electricity`: банки энергии, генераторы, потребители |
| **Spacebuild (SB)** или **CAF** | Устройства на ресурсе `energy`: реакторы, аккумуляторы, сети |

Модуль сам определяет, какие системы присутствуют на сервере, и работает
с теми из них, что установлены.

> **Совет:** если не установлен ни JMod, ни Spacebuild/CAF — связывать будет
> нечего. Установите хотя бы один из них.

## Возможности

- Единый тул связи для устройств JMod (`Electricity`) и Spacebuild/CAF
  (ресурс `energy`).
- **Равный делёж энергии**: суммарный запас связанных устройств делится
  на равные доли с учётом их ёмкостей — энергия идёт туда, где её меньше.
- **Правила сети**, которые не позволяют энергии пойти вразрез логике:
  - генератор → банк или потребитель — разрешено;
  - банк ↔ банк — равный делёж;
  - потребитель → кто угодно — **запрещено**;
  - банк → генератор и генератор ↔ генератор — **запрещено**.
- **Автоопределение ролей** по имени класса:
  - генератор — `generator`, `gen_`, `_gen`, `powersource`, `reactor`;
  - потребитель — `turret`, `sentry`;
  - накопитель — всё остальное (банки, батареи).

## Консольные команды

| Команда | Назначение |
|---|---|
| `sbjmod_transferlog 1` | Показывать перекачку энергии в консоли (0/1, сохраняется) |
| `sbjmod_test_energy` | Диагностика устройства под прицелом: роль, тип, каналы заряда |

Пример вывода диагностики для банка JMod:

```
[SBJMOD] === Диагностика: ent_jack_gmod_ezpowerbank ===
Роль: bank | Тип: jmod
GetElectricity -> ok=true val=420
MaxElectricity = 1000
[SBJMOD] === Конец диагностики ===
```

## Установка

1. Установите зависимости — JMod и/или аддоны на базе Spacebuild/CAF.
2. Подпишитесь на аддон в Мастерской или распакуйте его в
   `garrysmod/addons/`.

## Быстрый старт

1. Заспавньте банк энергии (например, `ent_jack_gmod_ezpowerbank` из JMod)
   и генератор.
2. Возьмите тул **SB <-> JMod Link** (категория Construction) и кликните
   по первому устройству, затем по второму — связь создана.
3. Включите `sbjmod_transferlog 1`, чтобы видеть поток энергии в консоли.

## Структура аддона

- `lua/autorun/` — ядро: таблица
- `lua/SB_JMOD`, определение типов устройств.
- `lua/autorun/transfer.lua` — модуль перекачки энергии.
- `lua/weapons/gmod_tool/stools/` — тул связи.
