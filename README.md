# SB <-> JMod Link

**Версия: 7.3**

Аддон для Garry's Mod, который связывает энергосистемы **Spacebuild (SB)**, **JMod** и **CAF (Resource Distribution / Life Support)** в единую сеть. Перекачивает энергию между банками JMod, генераторами SB и хранилищами CAF (`storage_energy` и любыми другими устройствами, зарегистрированными в RD-сети).

> ⚡ Простой пример: банк JMod питает генератор SB, а хранилище CAF заряжается от реактора — всё через один тул.

---

## Возможности

- **Двусторонняя перекачка энергии** — Spacebuild (`energy`) ↔ JMod (`Electricity`) ↔ CAF/RD.
- **Умное распознавание устройств** — через `RD.GetEntityTable`: любые девайсы Life Support цепляются без списков исключений.
- **Тул «SB <-> JMod Link»** — соединение устройств в пару кликов.
- **Динамический трос** — физический трос между устройствами **бесконечно растягивается**, если оттащить устройство далеко, и **сам стягивается**, когда приборы снова сближаются. Альтернатива — визуальный лазерный луч.
- **EZ-батарея как расходник** — заряженную `ent_jack_gmod_ezbattery` можно **влить** в любое устройство сети одним нажатием E; пустая батарея исчезает с искрами. Работает с водяными насосами, верстаками, турелями, банками — со всеми структурами, которые распознаёт мод.
- **Удаление связей по клавише R** — наведи на устройство со связями и нажми R: уберутся все его соединения вместе с тросом.
- **Гибкая скорость перекачки** — от 1 до 100 000 ед/сек, задаётся в меню тула.
- **Горячая перезагрузка** — обновление аддона без перезапуска игры (`sbjmod_reload` / `sbjmod_reload_cl`).

## Установка

1. Скопируйте папку `sb_jmod_link` в `garrysmod/addons/`.
2. Убедитесь, что установлены и включены аддоны-поставщики ресурсов:
   - **Spacebuild / CAF** (Resource Distribution, Life Support);
   - **JMod**.
3. Перезапустите GMod **или** перезагрузите карту.
4. Включите RD **до** спавна накопителей — иначе устройства не попадут в реестр RD и не будут распознаны.

Структура аддона:

```
sb_jmod_link/
    lua/
        autorun/
            sb_jmod_link.lua                  — ядро: тул, идентификация устройств, связи, команды
            server/
                sb_jmod_ezbattery.lua         — серверная логика: вливание EZ-батарей в устройства
        sb_jmod/
            transfer.lua                      — насос (перекачка ресурсов)
            rope.lua                          — динамический физический трос
            caf.lua                           — мост RD/CAF
            autolink.lua                      — патч Auto Link Tool (rd3_dev_link)
```

## Использование

### Тул «SB <-> JMod Link»

Находится в категории **Construction**.

| Действие | Результат |
|---|---|
| **ЛКМ** по устройству | Выбрать первое устройство; второй ЛКМ — создать связь |
| **ПКМ** по первому устройству | Задать цель 1; следующая ПКМ — цель 2; ещё одна ПКМ — создать связь |
| **R** по устройству со связями | Убрать **все** связи этого устройства (вместе с тросом) |
| **R** по устройству без связей / в пустоту | Сбросить выбор |

В меню тула настраиваются:
- **Скорость перекачки** (ед/сек);
- **Физический трос** (вкл/выкл — иначе между устройствами рисуется лазерный луч);
- **Провис троса**.

### Динамический трос

Трос ведёт себя как настоящий кабель на катушке:

- оттащили устройство физганом хоть через всю карту — трос бесконечно удлиняется;
- принесли обратно — трос сам укоротился и снова слегка провис;
- обновление длины происходит каждые 0,2 секунды через `SetKeyValue("addlength", ...)`, без пересоздания констрейнта.

### Вливание EZ-батареи

1. Возьмите заряженную `ent_jack_gmod_ezbattery` (в руках или физганом).
2. Подойдите к устройству, которому нужен заряд, и наведитесь на **батарею**.
3. Нажмите **E** — заряд целиком перельётся в устройство, пустая батарея исчезнет с искрами.
4. Если ёмкость приёмника не влезла целиком — перельётся сколько можно, батарея останется с остатком, в чат упадёт точный отчёт.

Радиус поиска устройства — 150 ед. по умолчанию, меняется командой `sbjmod_ezbat_range <значение>`.

Пустые батареи по-прежнему подбираются в инвентарь JMod как обычно: если рядом нет совместимого устройства, E работает как стандартный подбор.

### Консольные команды

| Команда | Описание |
|---|---|
| `sb_jmod_dump` | Список всех связей: классы устройств, типы, скорость, ресурс (для админов) |
| `sbjmod_select` | Выбрать устройство под прицелом |
| `sbjmod_link` | Связать выбранное устройство с устройством под прицелом |
| `sbjmod_reset` | Сбросить выбор |
| `sbjmod_reload` | Перезагрузить серверные модули аддона (для админов) |
| `sbjmod_reload_cl` | Перезагрузить клиентскую часть (в консоль игрока) |
| `sbjmod_ezbat_range <N>` | Радиус поиска устройства при вливании батареи |

## Как это работает

Ядро аддона — функция `SB_JMOD.Identify`, которая определяет тип устройства:

1. **JMod** — энтити имеет методы `GetElectricity` / `SetElectricity`; ёмкость читается из поля `MaxElectricity`;
2. **SB** — энтити имеет методы `GetResourceAmount` / `SetResourceAmount`;
3. **CAF (RD)** — устройство зарегистрировано в RD-сети через `RD.GetEntityTable` (покрывает `storage_energy`, генераторы и любые другие девайсы Life Support);
4. Запасной вариант по префиксам классов (`storage_`, `generator_`, `other_`, `residue_`), если RD ещё не успел зарегистрировать свежезаспавненный девайс.

Связи синхронизируются с клиентом по сети (`SBJMOD_Links`, каждые 5 секунд) — для отрисовки лучей. Перекачка и динамический трос обновляются серверными таймерами. Вся работа с батареями и зарядом обёрнута в `pcall` — отсутствие какого-либо API у конкретного устройства не уронит сервер.

## Совместимость

- ✅ Spacebuild (энергосистема `energy`)
- ✅ JMod (ресурс `Electricity` — водяные насосы, верстаки, турели и другие EZ-машины)
- ✅ CAF / Resource Distribution — через реестр RD
- ✅ Auto Link Tool (`rd3_dev_link`) — подключает банки JMod к нодам RD-сети после патча из модуля `autolink`
- ✅ EZ-Battery (`ent_jack_gmod_ezbattery`) — как одноразовый носитель заряда

## Устранение неполадок

| Проблема | Решение |
|---|---|
| Тул пишет «Это не устройство SB/JMod/CAF» | Убедитесь, что RD включён **до** спавна устройства; пересоздайте устройство |
| В `sb_jmod_dump` у устройства стоит `?` | Адаптер не подошёл под класс — сообщите класс (из спавн-меню) |
| Связь создана, но энергия не идёт | Проверьте, что в `transfer.lua` есть ветка для типа `caf` через `RD.GetResourceAmount` / `RD.SetResourceAmount` |
| Тул не появился в меню | Полный перезапуск игры — тул регистрируется загрузчиком |
| Трос не стягивается обратно | Наберите `sbjmod_reload` — модуль троса должен перезагрузиться |
| E по батарее ничего не делает | Рядом нет устройства, которому нужен заряд, или батарея пуста — тогда это обычный подбор в инвентарь |
